The retrospective

What we learned that was not written down

Concurrency is the whole story. Sprint 03 was 73% idle; this sprint was 7%, across 11 concurrent worktrees with zero collisions. The enabling insight was conceptual — the constraint is the checkout, not the agent. The first plan serialised six design items because one persona owned two of them, which would have tripled wall-clock for nothing.

Gates fired; prose did not — from the same document. DES-03's hero-eligibility rules were expressible as code and shipped exactly. Its homepage diversity rule and its desktop rail existed only as prose and a drawing, and neither reached production. The front page still shows one category thirteen times, and the spec had already measured that before the build began.

Which documents changed

  • skillcentral/skills/startsprint/SKILL.md — orca terminal send types but does not submit; watcher clustering and gate-output noise.
  • skillcentral/skills/endsprint/SKILL.md — run-stats must take every tree, not three.
  • Six commits to hire personas, authored by the hires themselves — design-systems-engineer (×3), creative-director, head-of-seo-content.
  • …/Executive/ceo-hellokahwin.md — written last: reporting a conclusion from a summary, and the verification shape that recurred ~12 times in one day.
  • New backlog items: CONT-15, RISK-10, PLAT-17, PLAT-18.

What we did twice that we should never repeat

Checked a proxy with a pattern nobody tested — about twelve times in one day. A space in the user path broke three separate commands; CRLF made two diffs report everything as changed; a grep for Kredit returned zero on a page carrying forty credits under an English label. Two would have produced a false accusation against an agent that was right.

What we nearly shipped, and what caught it

  • An agent sent to fix code that did not exist in its tree — UI-01 was dispatched into a worktree 42 commits behind master with zero of the target code. Caught by checking the base before dispatching the rest.
  • A social-video producer nearly assigned a CSS grid bug — the bare name creative-director resolves to the wrong persona in a fresh worktree.
  • A gate that could never have been proven — pre-fix production was captured as committed fixtures before any fix shipped, so UI-06 could show its gate failing on a known-bad input.
  • Evidence being silently destroyed — PLAT-15's first reconcile overwrote seven records. It found this against its own item, fixed it, added regression tests and restored them.

Was everything shipped?

Yes. All 17 verified by the CEO against live production or the artefact itself, with evidence recorded separately from each agent's own claim. One item's self-declared “done” was reversed on verification rather than accepted.

What carries forward

Sprint 05's theme is already written, and it is not a new art direction. Build the composition DES-03 already specifies: write the missing diversity rule (it does not exist — the spec's cross-reference is dangling), build the 300px desktop rail and the in-article table of contents, and add the mid-size image variant that would let photographs fill a frame.

Also carried: CONT-15, RISK-10, PLAT-13, PLAT-14, PLAT-17, PLAT-18, DES-14/15/16, UI-14/15/16, COPY-01, CONT-13/14, RIGHTS-02. SEO-04 stays parked — the diagnosis has not changed.
