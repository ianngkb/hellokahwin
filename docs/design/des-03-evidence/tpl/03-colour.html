03

Colour — two palettes, one exposed, every ratio measured

The dark-mode ruling, and exactly what it obliges

The decision of 2026-07-14 stands: dark is not reachable by a reader, there is no ThemeProvider and there is no toggle. That is the CEO's ruling of 28 Ogos 2026 and this document does not reopen it. What the ruling does not do is excuse the system from defining dark. So: light is complete on the base, dark redefines only the semantic layer, and no colour anywhere has its sole definition inside a dark block. Both palettes are specified; one is exposed. That is what globals.css already asks for in its own comment — keep this palette in sync so dark can be switched on later — and it is the only arrangement in which that comment can be true.

3.1  Two layers, and the rule that makes the ruling enforceable

Every colour value in the system lives in the primitive layer, on the bare :root, light and dark alike. Nothing consumes a primitive directly. Components read only the semantic layer, and the dark block redefines semantics by pointing them at primitives that are already defined. Switching dark on later is then one class on <html> and nothing else — no new hex, no second stylesheet, no audit.

:root{
  /* PRIMITIVES - every value the system owns, light and dark, defined once, here.
     Nothing below this block introduces a colour. */
  --hk-parchment-100:#EDEAE1;  --hk-parchment-200:#E3DFD4;
  --hk-parchment-300:#C9C3B6;  --hk-parchment-400:#A89C88;
  --hk-ink-900:#16130F;        --hk-ink-600:#4A443C;      --hk-ink-500:#5A5348;
  --hk-gold-700:#725825;       --hk-gold-400:#C9A253;
  --hk-oxblood-700:#6B2130;    --hk-oxblood-300:#D98C7A;
  --hk-night-900:#14110D;      --hk-night-800:#1E1A15;
  --hk-thread-500:#A8823C;     /* decorative hairline ONLY - see 3.5 */

  /* the alpha ladder. Rules and stripes are tints of the ink, not new colours,
     which is how a page renders in four hex values and still has furniture. */
  --a-tint:5%;   --a-hair:12%;  --a-rule:22%;  --a-boundary:47%;

  /* SEMANTIC - LIGHT, complete. Components read ONLY these. */
  --bg:         var(--hk-parchment-100);
  --bg-raised:  var(--hk-parchment-200);
  --fg:         var(--hk-ink-900);
  --fg-muted:   var(--hk-ink-600);
  --fg-dim:     var(--hk-ink-500);
  --accent:     var(--hk-gold-700);
  --alert:      var(--hk-oxblood-700);
  --tint:       color-mix(in srgb, var(--fg) var(--a-tint),     transparent);
  --hair:       color-mix(in srgb, var(--fg) var(--a-hair),     transparent);
  --rule:       color-mix(in srgb, var(--fg) var(--a-rule),     transparent);
  --boundary:   color-mix(in srgb, var(--fg) var(--a-boundary), transparent);
  --focus:      var(--fg);
}

/* SEMANTIC - DARK. Redefines the semantic layer and the two alphas that must
   change, and NOTHING ELSE. Not user-reachable today; kept correct on purpose.
   .hk-dark is the class, applied to <html> the day the toggle is built. */
.hk-dark{
  --a-hair:11%;  --a-rule:20%;  --a-boundary:37%;
  --bg:         var(--hk-night-900);
  --bg-raised:  var(--hk-night-800);
  --fg:         var(--hk-parchment-100);
  --fg-muted:   var(--hk-parchment-300);
  --fg-dim:     var(--hk-parchment-400);
  --accent:     var(--hk-gold-400);
  --alert:      var(--hk-oxblood-300);
  /* --tint/--hair/--rule/--boundary/--focus need no redefinition: they are
     already expressed in terms of --fg, so they invert with it. */
}

Why the alphas differ between the themes

A tint of ink on parchment and a tint of parchment on night are not symmetric — light ink on a dark ground reads stronger at the same alpha. The two boundary values were tuned to the same target, the 3:1 non-text floor, and land at 3.06:1 and 3.05:1. The alphas are numbers in the primitive layer, not colours, so the dark block still introduces no colour of its own.

The check the DSE runs before merging

Grep the stylesheet for a hex literal or an rgb() inside any .hk-dark, [data-theme] or prefers-color-scheme block. The correct count is zero. One hit means a colour exists that light has never seen, and the palettes have started to drift — which is the exact failure the 2026-07-14 comment was written to prevent.

3.4  The one-colour rule, and how the count actually holds at four

DES-01 fixed the ceiling: any single page renders in at most four palette values plus photography. That is the one thing every premium reference in the market survey agreed on — Carats & Cake 2, Dentelle 5, Alia Bastamam 5, PartySlate 6, against nikahsatu's 50 and mingguanwanita's 66. It is also the cheapest discipline available: it costs nothing and it is the thing a reader feels as someone is in charge here.

Obeying it literally used to be impossible, because DES-01 also listed a raised ground and a hairline as separate tokens, which takes a page with rules and stripes to six. The resolution: every rule, stripe, separator and boundary is an alpha of the ink, so it is a tint of a colour already on the page rather than a new one. A page therefore renders in exactly four hex values.

The decision that keeps the third row at four, and it is mine

Oxblood and gold never appear on the same page. On a surface that carries an alert, oxblood takes the accent slot and gold stands down — labels and credits render in --fg-muted instead. This is not a contrivance to save the count. An error screen with a decorative gold eyebrow above a red warning is a page with two accents competing for the same attention, and the warning loses. One accent per surface; the surface decides which.

3.5  Three colour rules that are not negotiable downstream

No text over a photograph

Anywhere. A contrast ratio against a photograph cannot be measured, so it cannot be asserted, so the pairing does not exist. Headlines, decks and credits all sit on the ground. Every credit in every screen below does.

Thread gold draws nothing that matters

2.95:1 on parchment. It fails the 3:1 non-text floor, so it may not border an input, ring a focus state, or carry text at any size. It is a decorative rule. If a boundary needs to be seen, it is --boundary.

No pure black, no pure white

Measured: 18.52:1 against 15.39:1, for no readability gain and a harsher page. Every measured premium brand in the market survey softens at least one side. This softens both, which is a stronger reading of the same instinct.
