7.3  The three loading layers

Named once so no two components invent their own timing. 0–300 ms: nothing renders — a flash of a skeleton under 300 ms reads as flicker, not feedback. 300 ms–3 s: the skeleton, --skel blocks matching the true height of what is loading, so the page does not jump when content arrives. ≥3 s: a 2 px --accent bar plus “Sedang dimuatkan…” in an aria-live="polite" region, so a slow connection is told something is still happening rather than left looking broken.

7.4  The surface no page type owns, and how it came to ship blank

Why this is here at all

This DoD names three page types. Not-found and error belong to none of them and are linked from all three — the search box, a stale category link, a dead external backlink all land here. DES-07 measured what that gap costs: the shipped 404 renders zero server characters, one empty hidden div, 360×900 px of white with scripting off, and /cari?q= stayed blank for 23.79 s. Nobody specified this surface, so nobody built it. Copy below is carried verbatim from DES-07 §9.3, drawn in Warkah's components.
