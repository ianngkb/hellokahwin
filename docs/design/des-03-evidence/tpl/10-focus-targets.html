10

Focus, targets and announcements

10.1  Focus ring

DES-07 §10.4 flagged the shipped ring — focus:ring-ring/30 — at 1.96:1 against the background, under the 3:1 floor WCAG 2.2 SC 1.4.11 sets for a non-text UI boundary. This specification sets the ring at var(--focus), which resolves to --fg at full opacity: 15.39:1 in light, 15.65:1 in dark — both measured in des-03-evidence/contrast-2026-08-28.txt. DES-07 named this fix as owed to DES-05; it is specified here so DES-05 receives a number rather than a complaint.

.s-focus{outline:2px solid var(--focus);outline-offset:2px;}

10.2  Target size

Every interactive element in this document is ≥44 px in its smaller dimension, matching DES-07's own floor and directly fixing the 40 px pill button DES-07 found on the shipped error boundary (§7.4, E3/E4).

10.3  Live regions

Exactly one aria-live="polite" region per page, reused by three states so a screen-reader user is not registered to three separate announcers: the §7.3 loading bar at ≥3 s, Muat lagi's result count after a catalogue append, and a section-error retry's outcome. A visual-only state change — the chip's aria-pressed fill in §8 — needs no live region because the control itself already exposes the state.
