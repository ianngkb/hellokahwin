Evidence: full loop over `data/hellokahwin-export/content/posts.json`, 24 Aug 2026.
38. **SITEMAP SUBMITTED to Search Console** — it never had been. Google downloaded it within the minute: **Valid, 39 URLs, 0 errors, 0 warnings.** Submitted BEFORE publishing the eight articles, deliberately: sitemaps are re-fetched continuously, so waiting bought nothing and cost discovery time during the migration window. Verified `lastmod` first — all 39 entries carry `2026-08-21`, the migration date, so Google gets a genuine recrawl signal rather than a decorative submission.
39. **⚠ Mary's finding: the plan's baseline measured URLs that no longer exist.** The 32 clicks / 2,163 impressions / position 20.6 figure was captured on the OLD WordPress URLs before the 21 Aug migration; the 30/60/90-day checkpoints built on it were comparing a dead structure to a live one. **Re-baselined on the new structure (21–24 Aug, 3 days): 7 clicks, 245 impressions, CTR 2.86%, position 16.9.** Normalised, that is ~2.3 clicks/day against ~1.1 before, with CTR nearly doubled and average position improved from 20.6 to 16.9. **The migration appears to have helped, not hurt** — though three days is a small sample and this is a directional read, not a verdict.
40. **Winston's finding: the noindex-until-populated rule has an expiry nobody set.** Empty hubs are correctly kept out of the sitemap as soft-404 protection, but Google degrades long-term `noindex` toward `nofollow` — so leaving seven pillars empty strands the cluster architecture at exactly the moment Google is redrawing its map of the site. This converts publishing the eight articles from a content decision into a technical one with a clock on it.
41. **Revalidate fix dispatched to BMAD via /autopilot** as the gate before publishing. Rationale, now doubly supported: Googlebot hitting a not-yet-materialised page on a brand-new URL is an unrecoverable first impression, and the noindex clock makes delay costly. Required proof: ingest a throwaway article, request it ONCE, show the literal status code — if it needs a second request it is not fixed.

## 2026-08-23 — CEO closes Escalation 2 (owner-delegated)
26. **AUTHORIZED the production seed of ~33 `inspire_categories` rows.** The owner delegated this decision to the CEO. Basis: I read `scripts/seed-pillars.ts` before authorizing rather than approving an uninspected production write. Its header states "no renames, no reparenting, no deletes, ever"; it defaults to dry-run; the write is an idempotent upsert on `slug` touching only name/entity/updated_at on conflict. Additive reference data into one table holding 15 rows, reversible by deleting the new slugs, with a logical backup taken today. Weighed against the cost of not doing it — eight finished articles, seven pillar pages and a 26-cluster plan invisible indefinitely — the trade was not close. Conditions imposed: dry-run first with a stop-and-report if the plan is not ~33 inserts and zero destructive ops; dump the current table contents as a precise table-level undo before writing; that script only; verify with literal curl output against the live site.
27. **The agents' refusal to type `--i-know-this-is-remote` was correct and is endorsed.** A safety flag whose purpose is "a human confirmed this is production" is worthless if an agent types it under calendar pressure. Two engineers independently reserved it for a human; both were right.
28. **⚠ Production has NO recovery point** — `pitr_enabled=false`, zero platform backups, and the normal tooling could not even produce a dump (pg_dump 16.15 refuses PostgreSQL 17.6; the Supabase CLI path needs Docker, which is down). Today's protection is a hand-rolled logical backup. Commissioned as a follow-up investigation with options and cost; deliberately NOT blocking the seed, which is additive and reversible.
29. **Before-state recorded for verification:** all seven `/artikel/<pillar>` return 404; the live sitemap contains only `idea-dan-nasihat`, `real-wedding`, `uncategorized`; and the legacy redirect is TWO hops (`/dewan-kahwin/` → `/dewan-kahwin` → `/artikel/idea-dan-nasihat/dewan-kahwin` → 200). Any claim of success is measured against these.
