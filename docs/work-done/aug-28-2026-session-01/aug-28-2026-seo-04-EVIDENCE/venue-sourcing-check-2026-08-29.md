## Answer to the brief's question

**Yes — nikahsatu.com is a paid/owned relationship, not independent coverage.**
All four named brands are commonly operated: nikahsatu.com's own footer reads
"© 2019 NikahSatu by Zest Venture Sdn Bhd," and Arjuna is independently
reported as run by "Zest Venture Sdn Bhd (842187-P)" — the same company. Every
one of the four brands' own social channels routes booking to nikahsatu
directly (tinyurl.com/Whatsapp-Nikahsatu; the JIWA Damansara launch post
published under nikahsatu's own brand). The only page anywhere carrying a
price or a pax figure for any of the four is the nikahsatu.com venue page
itself — never the venue's own domain (villarimbaflora.com: zero RM strings,
zero pax strings), never an independent rate card.

already recorded in `docs/boardroom/ceo-memory.md` on 27 Aug 2026 ("RESOLVE

what that means for the 29 Aug re-dispatch.
