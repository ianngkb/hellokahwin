## Blast radius

This change is **not code-only**. It has three parts with different reversibility:

| Part | Reversible by | Destructive? |
| --- | --- | --- |
| Application code | `git revert` | No |
| `articles.cover_image_lqip` column (prod DDL) | `ALTER TABLE … DROP COLUMN` | Additive; drop loses only derived data |
| Backfilled placeholder values | recomputable from R2 at any time | No — derived, never a source of truth |

Nothing in this item deletes or rewrites an existing column, image, or article
row. The one new column is nullable and additive, and every value in it is
**derived** from a cover already in R2 — so the backfill can be recomputed from
scratch at any point by re-running the script. Losing the column costs a
re-run, never data.

## Order the production writes happen in

1. `ALTER TABLE "articles" ADD COLUMN "cover_image_lqip" text;` — additive and
   nullable, so the currently-deployed code (which never mentions the column)
   keeps working unchanged. Safe to apply BEFORE the deploy, and it must be:
   the new code selects the column.
2. Deploy the application code.
3. `pnpm backfill:lqip --db <prod>` — writes only `cover_image_lqip`, only on
   rows where it is null.

## Full revert

### Code

```bash
git revert --no-commit <ux-04 sha>
git commit -m "revert(ux-04): remove blur placeholders and restore the flat plate"
```

That returns every card and cover to `bg-muted` with no placeholder — the
pre-UX-04 behaviour, which is a degradation, not a break.

### Database

The column can be left in place after a code revert with **no effect**: nothing
reads it, and a stray text column costs one nullable field per article row. That
is the recommended rollback — dropping it throws away the backfill for no gain.

If it must go:

```sql
ALTER TABLE articles DROP COLUMN cover_image_lqip;
```

Run this ONLY after the code revert is live. The reverse order — dropping the
column while the new code is still deployed — takes every public page down,
because the queries select it by name. This is the one genuinely dangerous
sequence in this item.

### Re-deriving the backfill

```bash
pnpm backfill:lqip --db <url> --force
```

`--force` re-derives every row rather than only the null ones. The source images
in R2 are never modified by any part of this item, so this is repeatable
indefinitely and converges on the same values.
