# Decisions — hellokahwin vision alt text (D24)

- [2026-09-04] Extracted the document walk into `scripts/seo/_content-images.mts` and moved `backfill-image-alt.mts` onto it, rather than copying a second walker into the new script. The new script finds its 369 targets by recomputing `fallbackImageAlt(title, ordinal)`; two walkers that disagreed about ordinals would have handed a photograph a description of a different one. 15 unit tests now cover the walk, which had none.
- [2026-09-04] Identify targets by exact string match against a recomputed `fallbackImageAlt(title, ordinal)`, not by a `/— gambar \d+$/` regex. A regex would also match an alt an editor happened to write that way, and could not notice an ordinal that had drifted. The extract returning exactly 369 across exactly 14 articles is the proof the two walks agree.
- [2026-09-04] Backup table named by the shared `snapshot()` helper (`articles_backup_<runId>_visionalt`) rather than the literal `articles_backup_20260904_visionalt` the brief spells. The helper's per-run id is what makes a second run on the same day a hard failure instead of a silent reuse of the first run's snapshot; hardcoding the date would give that up. Same table, same day, same slug — the run id is the only difference.
- [2026-09-04] Fetched the `mid.webp` rung for the vision pass (14 KB–349 KB, all 369 present and under the 350 KB ceiling) rather than `high.webp`, which runs to 1.4 MB a frame. `mid` is 1400px, which is more than enough to tell a pelamin from a hantaran tray.
- [2026-09-04] Descriptions carry no personal names, even though the articles name the couples in prose. The brief allows a name only where a CAPTION names it, and effectively no caption does. `pengantin` / `pasangan pengantin` throughout.
- [2026-09-04] The apply script enforces its rules as hard failures for the whole run, not skipped rows: a half-described article looks finished and is not.
- [2026-09-04] No automated Malay-language check on the generated text. Venue and vendor names on these pages are English ("The Danna Langkawi", "Sime Darby Convention Centre"), so any English-stopword rule would reject correct alts. Language is held by the generator brief, the humanizer pass, and a read of the sample instead.
- [2026-09-04] Review found the walker consumed an ordinal for a src-less figure where `article-renderer.tsx` numbers one only inside `if (src)`. Changed the walker to match the renderer rather than assert-and-abort, because a census over all 102 published articles found zero src-less figures and zero galleries, and `--extract` before and after the change picks a byte-identical set of 369 targets. The alternative — freezing the old counting to protect the 369 alts already stored — would have kept a known divergence alive for a case that does not exist.
- [2026-09-04] Kept `updated_at = now()` on the write, against a review finding, and recorded it in the UNDO document. The finding itself offered "record the re-dating as an accepted consequence". The rendered HTML of these pages genuinely changed, so a `dateModified` that stayed put would be the false claim; and the repo deliberately ties the visible "Disemak" date to `dateModified` so the two cannot disagree. Freezing it would also have meant changing `applyContentMigration`, which three already-shipped scripts share, on the day of a production write.
- [2026-09-04] Descriptions now carry the `src` they were written from and the apply refuses a mismatch. `id` + `ordinal` names a position, not a photograph; an image swapped between the extract and the apply would have inherited the previous frame's description with every check still passing.
- [2026-09-04] Live verification widened from the 3 essays the brief named to all 14, with paths resolved through the sitemap at run time rather than hardcoded, so an article recategorised later is followed instead of read as a 404.
- [2026-09-04] Did not automate a "is this Malay" check. Stated in the script header that the language and the fidelity of each description are held by a person reading the dry-run report, rather than implying a gate that does not exist.
