What I did find:

MINOR | scripts/seo/vision-alt.mts:387 | When `rows` is empty (e.g. `--descriptions` pointing at `[]` after a completed apply — the natural "did it land?" re-check), `Math.min(...[])`/`Math.max(...[])` yield `Infinity`/`-Infinity` and the mean divides by zero, so the report reads `Length Infinity–-Infinity characters ... mean NaN` while claiming success. | Guard the stats line: `if (rows.length === 0) out.push('No descriptions to write.', '')` and only compute the min/max/mean block when `lengths.length > 0`.

MINOR | scripts/seo/vision-alt.mts:404 | The "Every alt written" table interpolates `r.oldAlt` (which is `${article.title} — gambar N`) and `r.alt` raw into a pipe-delimited Markdown row; an article title or description containing `|` silently splits the row into extra columns and misaligns the whole table the reviewer is meant to read. | Escape the cells, e.g. `const cell = (s: string) => s.replace(/\|/g, '\\|')`, and wrap `r.slug`, `r.src`, `r.oldAlt` and `r.alt` in it (same for the per-article table).

MINOR | scripts/seo/vision-alt.mts:302 | `--extract` writes without `mkdirSync`, so a path in a not-yet-created directory throws a raw ENOENT after the full DB scan; and with zero targets it still writes a file containing a single `\n`, which a JSONL reader sees as one empty record rather than an empty extract. | `mkdirSync(dirname(extractPath), { recursive: true })` before writing, and write `lines.length ? lines.join('\n') + '\n' : ''`.

MINOR | scripts/seo/vision-alt.mts:31 | The header states that if the walkers disagree "the count comes back short and the run stops instead of describing the wrong photograph", but nothing asserts a total. An ordinary editorial action — renaming an article after the backfill ran — makes `fallbackImageAlt(a.title, ordinal)` stop matching the stored string, so those images drop out of `findTargets` silently, are never extracted, never described, and the run reports success while they keep `Old Title — gambar N` forever. | Either soften the comment to say the mismatch is silent, or add the promised gate: pass an expected target count (e.g. `--expect 369`) to `--extract` and throw when the discovered total differs, so drift is loud rather than invisible.

MINOR | scripts/seo/vision-alt.mts:92 | `flag()` returns `argv[i + 1]` unconditionally, so `--undo --report r.md` silently binds `undoDir` to the literal string `--report` and the dry run creates a directory named `--report`. (Copied from `backfill-image-alt.mts`, so both scripts share it.) | Reject a value that starts with `--`: `const v = argv[i + 1]; if (v === undefined || v.startsWith('--')) throw new Error(`${name} needs a value`); return v;`.
